Ponte DualSense–Switch 2

Um controle de PS5 jogando no Switch 2 como se fosse um Pro Controller, com gyro e vibração, usando duas ESP32 clássicas.

Arquitetura

DualSense ))) BT ))) [Placa-MicroB ds5-side] ── UART2 921600 ── [Placa-USBC switch-side] ))) BT ))) Switch 2
                     Bluepad32 (BTstack)    GPIO17 TX → GPIO16 RX   Pro Controller 057E:2009
                     COM4 · CH9102          GPIO16 RX ← GPIO17 TX   BTstack HID (base JereDev)
                                            GND ─────── GND         COM5 · CP2102
                                            5V  ─────── 5V  (opcional: um USB alimenta as duas)
frame: AA 55 | type | len | payload | crc8      type 0x01 STATE  ·  type 0x02 RUMBLE
